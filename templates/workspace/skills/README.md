# Skills

Skills are Durable Intent: behavior knowledge on disk so you stop re-explaining it every session.

Keep the always-on packet in `../primer.md`. Put long procedures here.

Each skill lives at `skills/<name>/SKILL.md`. Create one with `kac new skill <slug>`.

If you are about to paste the same paragraph into a third session this week, it wants to be a skill. If the skill exists and you still retype it, you have an invocation problem — point the agent at the file.
