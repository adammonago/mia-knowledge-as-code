# Retired knowledge

Deletion without annotation is the failure. When a claim expires, keep the file and fill three fields:

1. **stopped_asserting** — the claim as it stood, not a vague "deprecated"
2. **why** — provenance gap, better source, failed corroboration, policy change
3. **falsifiers** — when the retirement itself should be revisited

Copy `_template.md` or run `kac new retirement <slug>`. Retrieval should exclude these from primary answers and still be able to explain the lineage.
